# 🌸 Image Gallery

## 📌 About the Project
This project is a responsive Image Gallery developed using HTML, CSS, and JavaScript. It displays beautiful flower, rose, and lotus images with category filters and interactive navigation.

## ✨ Features
- Responsive design for desktop, tablet, and mobile.
- Image filtering by category: All Photos, Flower Photos, Rose Photos, and Lotus Photos.
- Hover effects and smooth transitions.
- Lightbox view to display images in full size.
- Next and Previous buttons for image navigation.
- Simple and user-friendly interface.

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

## 🚀 How to Run
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Create the `index.html` file using HTML and the `style.css` file using CSS.
4. Add all image files to the correct locations.
5. Link the CSS file to the HTML file using the `<link>` tag.
6. Open `index.html` in your browser or use the Live Server extension.
7. Click the category filters to view specific images.
